# Plan: API parity + agent-ergonomics wave → v0.5.0

Date: 2026-08-03. Owner: Claude (orchestrator) + delegate lanes. Branch: `feat/api-parity-0.5.0`.
Inputs: `work/audit-2026-08-03-spec-drift.md`, `work/audit-2026-08-03-docs-coverage.md` (two independent Luna xhigh audits, converging), plus live probes run 2026-08-03.

## Why

The repo's promise is **the full Exa API as an agent-first CLI**. Two audits against the live spec and all 186 docs pages found drift: a retired endpoint family we still ship, a new docs-only endpoint family we lack, one documented query param we cannot send, two advertised-but-unimplemented conveniences, and several contract-level enum/schema changes. This wave restores full parity and applies the rust-agent-cli + agent-ergonomics skill standards to every touched surface.

Ground truth from live probes (2026-08-03):

- `GET /research/v1` → **HTTP 410**, upstream tag `RESEARCH_RETIRED`, message says the Research API is retired.
- `POST /search` accepts BOTH `category: "research paper"` (legacy alias) and `category: "publication"` (canonical). Our typed flag rejects `publication` locally.
- `search --type deep-reasoning` already exists in the CLI (the documented replacement for Research).

## Design stance (the agent's-eye view)

Governing rule (agent-ergonomics One Rule): *the first thing an agent instinctively tries must either work or fail with an exact, copy-pasteable next command.* Applied here:

1. **Retired ≠ vanished.** An agent with stale knowledge WILL type `exa-agent research create …`. If we delete the subcommand outright, clap answers "unrecognized subcommand" — a dead end. Instead `research` stays as a **local stub** that exits 1 (usage) with error code `research_retired`, a message naming the replacement, and `suggestedCommand: "exa-agent search \"<query>\" --type deep-reasoning"`. No network call is burned to learn this. The generated ops, overlay entries, and request fixtures are removed.
2. **Accept both enum spellings, send canonical.** `--category` gains `publication`; `research paper` remains accepted (upstream aliases it) but is coerced to send `publication` and the envelope carries a `warnings[]` entry `legacy_category_alias`. Same pattern for agent data-source providers: re-vendored enum is `fiber`/`particle`; the CLI coerces legacy `fiber_ai`/`particle_news` inputs with a warning instead of rejecting. Input forgiveness with a visible canonical form — never a silent rewrite, never a pointless rejection.
3. **No advertised-but-broken surfaces.** `websets imports create --csv/--url` currently return `not_implemented`. That is the worst ergonomic state (worse than absent — it invites a retry loop). We implement the documented two-step flow (create → PUT bytes to `uploadUrl`), because the whole point of a CLI convenience is collapsing a multi-request workflow into one command an agent can't get wrong.
4. **Docs-only endpoints go through the overlay**, exactly like `/context` did: websets exports get typed commands with schemas defined in `overlay.toml`, marked `defined_by_overlay`, provenance recorded.
5. **Deprecated upstream fields stay callable but say so.** `--start-crawl-date`/`--end-crawl-date` keep parsing (agents with old scripts must not hard-break) but emit warning `deprecated_upstream_field` noting the API ignores them; help text says "Deprecated upstream; ignored by the API."
6. **Discoverability beats `--set`.** Named flags are added only where the audit showed real agent traffic value: search `--output-schema`, `--system-prompt`; agent runs create `--system-prompt`; contents `--highlights`. Everything else stays reachable via the documented `--set`/`--body` escape hatches — flag inflation is its own ergonomic failure.
7. **Out of scope, recorded as decisions:** OpenAI-compat routes (`/chat/completions`, `/responses`) stay raw-only — they duplicate `search`/`answer`/`agent runs` which we expose natively, and D16 already defers them; we add a decisions.md addendum (D40) and a robot-docs note naming `raw` as the path. MPP/x402 access modes are an auth transport question, not an endpoint gap: out of scope, noted in D40.

### Wave 2 — two parallel Luna xhigh lanes, worktree isolation

Disjoint-enough file ownership, merged by the orchestrator. Both branch from the Wave-1 commit.

**Lane A — Websets family:**
- Overlay-defined `websets exports create <webset-id>` and `websets exports get <webset-id> <export-id>` (docs: websets API guide "Exports" section; request/response schemas transcribed into `overlay.toml` with provenance URLs). Destructive? No — but `create` is a POST, so idempotency-sensitive per D7 (no auto-retry without key).
- `websets get --expand items` as a real query parameter (fix: `--set expand=items` currently lands in a GET body — that bug is why a typed flag is required, not merely nice).
- Implement `websets imports create --csv FILE` / `--url URL`: create import → PUT the bytes/redirect to `uploadUrl` → single envelope reporting both steps, with the upload step's failure mode distinct (`import_upload_failed`, retryable, suggested recovery command `websets imports get <id>`). `--dry-run` previews the create body and states the upload step that would follow.
- Tests: fixture-driven (local server), including upload-failure recovery and expand-in-query assertion.

**Lane B — named-flag ergonomics:**
- `search --output-schema JSON`, `search --system-prompt TEXT`, `agent runs create --system-prompt TEXT`, `contents --highlights [QUERY]` (mirroring existing highlight semantics on search).
- Help text and generated skill/robot-docs refreshed; every new flag has a dry-run golden.
- Constraint: zero new abstractions — these plug into the existing overlay/flag machinery.

## Review protocol

- After each wave: `delegate pi safe --model grok` + `delegate pi safe --model kimi` on the wave diff (same brief, parallel). Grok severity is re-ranked by the orchestrator (standing rule); a dead Kimi run counts as no review.
- Fixes: Luna xhigh with the adjudicated findings list; every nontrivial Luna fix round is followed by a fresh review pass (Luna fix-regression rule).
- Endgame: Sol xhigh + native Opus subagent(s) review the full branch diff vs main → Opus fixes → final Sol xhigh pass + orchestrator's own review, orchestrator fixes residuals directly.
- Ship gate: `cargo xtask ci` + live smoke + Trey's explicit sign-off before anything touches main. **Push to feature branch is allowed; main is untouchable without sign-off.**

## Risks

- **Overlay merge conflicts between Wave-2 lanes** — different sections, orchestrator merges; lanes forbidden from tree-wide git commands.
- **Exports schemas are docs-transcribed** (no OpenAPI source): live smoke is the real validator; overlay marked with provenance so future drift audits check it.
- **Upstream alias behavior could change** (e.g. `research paper` starts erroring): coercion means we always send canonical, so we are insulated.
- **Luna fix-round regressions**: mitigated by the mandatory fresh-review-after-fix rule.
